# Snake-Mania 🐍

I originally made this in 2021 when I started learning web development as a learning project. It has since been updated with a fully responsive modern UI and seamless mobile support!

## Features
- **Responsive Design**: The game layout adapts smoothly to both desktop and mobile screens.
- **Mobile Controls**: Features a custom-designed circular D-Pad for playing on touchscreen devices.
- **Native UI Modal**: A sleek, non-blocking modal gracefully handles the Game Over state.
- **High Score Tracking**: Automatically saves your highest score using local browser storage.

## How to Play
- **Desktop**: Use your keyboard's Arrow Keys (`Up`, `Down`, `Left`, `Right`).
- **Mobile**: Tap the directional buttons on the on-screen circular D-pad.
- Eat the food to grow your snake and increase your score.
- **Don't touch the walls or your own tail**, or it's game over!

## Tech Stack
- HTML5
- CSS3 (Flexbox & CSS Grid)
- JavaScript
